# PHP Typehints Extra

![Build](https://github.com/pronskiy/php-typehints-extra/workflows/Build/badge.svg)

<!-- Plugin description -->
A PhpStorm plugin that adds extra type-hinting capabilities to PHP code.
<!-- Plugin description end -->

## Compatibility

PhpStorm 2026.1 and later.

## Installation

- Manually:

  Download the [latest release](https://github.com/pronskiy/php-typehints-extra/releases/latest) and install it manually using
  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>⚙️</kbd> > <kbd>Install plugin from disk...</kbd>
